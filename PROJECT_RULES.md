# Правила проекта WoW Minmaxxer

Кор-правила, которые соблюдаются при каждой правке сайта. Новые правила добавляются сюда, изменения сайта — в [CHANGELOG.md](CHANGELOG.md).

## 1. Названия из мира WoW

- Сначала английское название, русское — в скобках: `Razorfen Kraul (Лабиринты Иглошкурых)`, `Corpsemaker (Труподел)`.
- Русское название пишем, только если оно подтверждено официальной локализацией: словарь `js/names.js` для мест, подземелий, NPC, классов, профессий и способностей; поле `ru` в `data/items.json` для предметов (ruRU-подсказки Wowhead).
- Если подтвержденного русского названия нет, пишем только английское. Не переводим сами и не придумываем.
- Новые зоны и подземелья WoW Forever (Zephras Isle, Riverglades, Excavation Site и другие) остаются на английском, пока нет официального перевода.
- В текстах базы знаний места помечаются `{{Name}}`, предметы — `[[ID]]`; формат «English (Русский)» собирается автоматически.

## 2. Данные

- Персонажи — только из armory [wow-classic-premium.com](https://wow-classic-premium.com/en/forever/armory). Бот читает страницы персонажей, которые разрешены в `robots.txt`; служебные адреса lookup/refresh (`/*/forever/armory?*action=lookup`) запрещены, их не трогаем и обновление на чужом сайте не запускаем.
- Карточки предметов — подсказки Wowhead (`nether.wowhead.com/forever/tooltip/item/ID`, en и ru), с кешем в `data/items.json`: каждый предмет запрашивается один раз.
- Рекомендации, маршруты и билды — из открытых гайдов; источник указывается в `KB.SOURCES` и в футере.
- Если данных нет (персонаж не в armory, у предмета нет характеристик), так и пишем на сайте, а не заполняем догадками.
- Скрипт Wowhead и картинки из игры на сайт не подключаем: Wowhead недоступен из России, а иконки — арт Blizzard. Значки слотов и классов — свои.

## 3. Управление составом

- Добавление, удаление и обновление — через GitHub issue по шаблонам `[add]`, `[remove]`, `[refresh]`. Бот (`.github/workflows/update.yml`) обрабатывает заявку, коммитит данные и закрывает issue с отчетом.
- Заявки принимаются только от логинов из `data/members.json`.
- По расписанию бот перечитывает armory каждые 6 часов.

## 4. Сайт

- Статичный сайт на GitHub Pages, без сборки: `index.html`, `css/app.css`, `js/*.js`, данные в `data/`.
- Интерфейс на русском, мобильный экран — основной.
- Отметки вех и пройденных подземелий хранятся только в браузере посетителя (localStorage).
- Каждая выкладка — новая версия: номер в `js/app.js` (`VERSION`), параметр `?v=` у файлов в `index.html`, запись в `CHANGELOG.md`, git-тег `vX.Y.Z`.

## 5. Тон

- Фан-проект, не связан с Blizzard Entertainment; это указано в футере.
- Советы формулируем как выводы из гайдов, а не как истину: где гайды расходятся, пишем об этом.
