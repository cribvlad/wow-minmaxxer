# Что нового

## v0.3.0 — 14.11.2026

- Главная страница — сводка по пати: последние изменения каждого персонажа, где качаться вместе, следующее подземелье по плану и самая полезная добыча для каждого (значок слота, предмет, кому, где взять).
- Селектор персонажей (список и чипы), разделы персонажа — вкладками: Обзор, Экипировка, Таланты, Кач, Билд, Профессии.
- План подземелий — сворачиваемыми блоками с отметкой «пройдено».
- Вкладка «Состав»: добавление персонажа по имени и фамилии, удаление, кнопка «Обновить статусы» — через заявки на GitHub, которые обрабатывает бот.
- Бот на GitHub Actions: каждые 6 часов и по заявке читает armory, сохраняет снимки и историю, догружает карточки предметов с английским и русским названием.
- Таланты любого класса берутся из armory, а не из ручных данных.
- Названия из мира WoW: сначала английское, русское в скобках (см. PROJECT_RULES.md).
- Минималистичный дизайн: спокойная темная тема, один акцент, цвета качества предметов как в игре.
